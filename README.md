# Red House Estate Services — Static Website

This repository contains a small static brochure site for Red House Estate Services.

Files:
- index.html — main site
- styles.css — styles
- script.js — small client JS

Contact phone number shown in header and contact section.

Deployment
- This site is a plain static site and can be served by GitHub Pages. After this commit, the site should be available at:

  https://RedHouseEstatesServices.github.io/RedHouseEstatesServices/

- If the site doesn't appear immediately, wait a minute for GitHub Pages to publish. If you prefer Netlify or Vercel for continuous deploys (recommended for forms), connect the repo to those services and they will auto-deploy on push.

Netlify Forms
- The contact form includes a Netlify Forms attribute (`data-netlify="true"). To use Netlify forms, deploy the site to Netlify and the form will be captured automatically.
